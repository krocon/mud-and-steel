# Geodata of `coastal_heights` (prompt 113)

Sources of the map `data/maps/coastal_heights/`, generated by
`tools/geo_import.py` (`just gen-geo coastal_heights`, docs/MAPS.md, "Maps
from real geodata"). The data shows the Marin Headlands north of San
Francisco (California): Point Bonita, Rodeo Beach and Rodeo Lagoon, Fort
Cronkhite and Fort Barry, Hawk Hill, Wolf Ridge, the Rodeo Valley, Fort
Baker, Horseshoe Bay and the south of Sausalito. The place is named only
here, in docs/SOURCES.md and in docs/MAPS.md, never in the game.

- `site.json`: the site description, with the Overpass query
  (`osm_query`), the query for the coast batteries
  (`fortifications_query`; its answer is not part of the extract, the
  battery places are copied by hand into `fortifications.works`, each with
  the OSM feature in `source`), the URL of the DEM tile and the retrieval
  dates.
- `osm.json.gz`: OpenStreetMap extract (retrieved 2026-11-23 07:21 UTC),
  reduced to geometry and the tags the importer reads (plus `historic`
  and `military`, `sources.extra_tags`); names, addresses and ids
  removed. © OpenStreetMap contributors, ODbL 1.0
  (https://www.openstreetmap.org/copyright). This file and the generated
  map are derived databases and available under the ODbL 1.0.
- `dem.json.gz`: crop of the Copernicus DEM GLO-30 tile N37 W123 in
  centimeters. Produced using Copernicus WorldDEM-30 © DLR e.V. 2010-2014
  and © Airbus Defence and Space GmbH 2014-2018 provided under COPERNICUS
  by the European Union and ESA; all rights reserved.

Regenerate the extract (raw downloads under `build/`, not in the
repository):

    python3 -I tools/geo_import.py extract assets-src/geo/coastal_heights/site.json \
        --osm build/geo_raw_113/osm_overpass.json \
        --dem build/geo_raw_113/copernicus_N37_00_W123_00.tif
