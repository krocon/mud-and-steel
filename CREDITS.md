# Credits

License and origin of every third-party source used in the game's assets.

## Assets

No third-party models, textures, animations or sounds are used so far. All models
and animations are generated by the project's own scripts:

| Asset | Origin | License |
|---|---|---|
| Infantry soldiers: body, uniforms, headgear, equipment, weapons, animations (`godot/assets/models/*/infantry/`) | own scripts, `tools/blender/build_soldier.py` and `tools/blender/soldier/` (prompt 005) | project's own |
| Placeholder tank, scale reference figure | own scripts, `tools/` | project's own |
| App icon (`godot/icon.svg`) | own drawing (prompt 044) | project's own |

## Reference data

Real dimensions (facts, not copyrightable) come from the sources named per value:
unit catalog entries in `data/catalog/` ([docs/SOURCES.md](docs/SOURCES.md)), weapon
lengths, barrel lengths and calibers in `tools/blender/soldier/weapons.py` (Wikipedia
articles, cited per weapon). Uniform colors in
`godot/assets/models/infantry/uniform_palettes.json` are own approximations of period
colors.

## Tools

Blender (GPL) and Godot Engine (MIT) are used to build and run the game; their
licenses do not extend to the assets made with them.

## Software in the released game

The released game contains Godot Engine (MIT) with its third-party components,
the Rust crates the GDExtension links (MIT, Apache-2.0, MPL-2.0 for godot-rust
and others) and Valve's Steamworks API library. Their notices and license texts
are in `THIRD_PARTY_LICENSES.txt` next to the game (made by
`tools/release/third_party_licenses.py`) and in the main menu under *Credits*.
The game's own license: [LICENSE.txt](LICENSE.txt).
